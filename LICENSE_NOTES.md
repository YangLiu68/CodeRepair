## Benchmark data

### First-party fixtures (`benchmarks/tasks/`)

All ten tasks (code, tests, hidden tests, issues and solutions) are original work written for this
project on 2026-10-14. They are not copied or adapted from public repositories or bug datasets and
will be released under the project license. The prompt-injection text in t10 is synthetic and points
only at the reserved `attacker.example` domain.

### Public subset (`benchmarks/public/`, Milestone 6)

Twenty-five tasks are derived from **QuixBugs** (Lin, Koppel, Chen and Solar-Lezama, 2017),
<https://github.com/jkoppel/QuixBugs>, commit `4257f44b0ff1181dedaedee6a447e133219fcebf`, retrieved
2026-10-15.

- **License:** the repository is distributed under the MIT License, "Copyright 2017-2019 James
  Koppel". The full text is included as `benchmarks/public/LICENSE-QuixBugs.txt`, which satisfies
  the MIT notice requirement for the redistributed portions.
- **Caveat recorded upstream:** QuixBugs' `legal_notes.txt` explains that the programs come from the
  defunct Quixey Challenge, that rights to the original code are unclear after the company's
  bankruptcy, and that the original author gave his blessing for the benchmark's release. We rely on
  the MIT grant and this statement; anyone redistributing the subset commercially should read that
  file themselves. Nothing here is legal advice.
- **What is included per task:** the buggy program verbatim (code and its specification docstring),
  test cases taken from `json_testcases/<name>.json`, and in harness-only files the lines that the
  upstream correction changes (`solution.json`, `solution.patch`). Upstream test harness files are not
  included.
- **Modifications:** programs are placed in an `algo` package; visible and hidden pytest files, a
  per-test time-limit `conftest.py`, a `pyproject.toml` and the issue text are generated by
  `scripts/build_public_subset.py`. Each `task.toml` records the upstream paths, commit and license.
- **No attribution inside `repo/`:** agent-visible files carry no QuixBugs name or header, to avoid
  cueing a model to recall memorised solutions. Attribution lives in `task.toml`, the license file,
  this document and BENCHMARK.md.

## Models and services

- **Claude (Anthropic API):** used through the API under Anthropic's terms. Repository content in a
  prompt is sent to Anthropic; secrets are redacted on a best-effort basis first. No live call has
  been made from this machine (no API key).
- **qwen2.5:7b (Ollama):** used locally for the M1 smoke run. Apache-2.0 per its model card.
- **qwen2.5:3b (Ollama):** used locally for the M5 benchmark. It is under the **Qwen Research License
  Agreement** (non-commercial research use), unlike the 7B model. It is not redistributed; the
  committed result files (`docs/results/`) record metrics and failure categories, not model outputs.
- No model weights are included in this repository.
